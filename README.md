# Banking Management System

A console-based Banking Management System developed in Python to practice Object-Oriented Programming (OOP), modular design, and file handling.

## Features

- Customer and account management
- Savings and current account types
- Deposit, withdrawal, and transfer operations
- Transaction status tracking
- Input validation
- Account and transaction reports
- File-based data persistence

*Note: Features should be listed here only after they have been implemented and tested.*

## Technologies Used

- Python 3
- Object-Oriented Programming
- Inheritance and polymorphism
- Encapsulation and abstraction
- Exception handling
- File handling
- Git and GitHub

## How to Run

1. Install Python 3.
2. Clone this repository:

   ```bash
   git clone https://github.com/Aun-Ali-70/Banking-Management-System-Python.git
   ```

3. Open the project directory:

   ```bash
   cd Banking-Management-System-Python
   ```

4. Run the application:

   ```bash
   python main.py
   ```

## OOP Concepts Practiced

- Inheritance: specialized account and transaction classes
- Encapsulation: protecting account state and balances
- Polymorphism: specialized transaction behavior
- Abstraction: defining common interfaces for related classes
- Composition: coordinating customers, accounts, and transactions
- Modular programming: separating responsibilities across files
